# Smart Fridge | Bootstrap

Bootstrap du projet **Smart Fridge** : apprendre à lire, interpréter et construire un diagramme de Gantt.

## 🎯 Objectifs

1. **Analyser un Gantt existant** : explorer le planning d'un projet qui ne s'est pas déroulé comme prévu et en tirer des leçons :
   - Quels éléments montrent que le projet ne s'est pas déroulé comme prévu ?
   - Quelles parties du projet étaient les plus sujettes aux imprévus ?
   - Ces imprévus ont-ils eu des conséquences sur d'autres parties du projet ?
   - Que pouvait faire l'équipe pour éviter de telles situations ?
   - Quelles sont les conséquences des différents retards ?
   - Quelles conséquences globales les retards ont-ils sur la suite du projet ?
2. **Construire notre propre Gantt** : pousser sur Git une version initiale, structurée et facile à faire évoluer, couvrant deux grandes parties :
   - la **préparation et le cadrage** du projet ;
   - la **construction et la livraison** du produit.
