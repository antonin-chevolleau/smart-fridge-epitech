# Smart Fridge | Bootstrap

Bootstrap Epitech du projet **Smart Fridge** : apprendre à lire, interpréter et construire un diagramme de Gantt.

## 🎯 Objectifs

1. **Analyser un Gantt existant** : explorer le planning d'un projet qui ne s'est pas déroulé comme prévu (« Yes Connect ») et en tirer des leçons :
   - Quels éléments montrent que le projet a dérapé ?
   - Quelles parties étaient les plus sujettes aux imprévus ?
   - Quelles conséquences ces imprévus ont-ils eues sur le reste du projet ?
   - Qu'aurait pu faire l'équipe pour les éviter ?
2. **Construire notre propre Gantt** : pousser sur Git une version initiale, structurée et facile à faire évoluer, couvrant deux grandes parties :
   - la **préparation et le cadrage** du projet ;
   - la **construction et la livraison** du produit.

## 🔍 Gantt d'exemple en bref

- 3 phases : **Design & Conception**, **App Dev**, **Release** sur 8 semaines à partir du 29/01/2018
- Légende : gris = fait, bleu = à faire, jaune = démarrage retardé, rouge = fin retardée
- Budget estimé **70 800** → réel **154 800** (≈ +119 %)

L'analyse détaillée est suivie dans [`todo.md`](todo.md).
